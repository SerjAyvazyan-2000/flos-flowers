# FLOS — салон цветов (Новосибирск)

Демонстрационный одностраничный продающий лендинг для салона цветов Flos Flowers.

- `index.html` — страница
- `assets/css/style.css` — стили (адаптив, анимации)
- `assets/js/main.js` — интерактив: прелоадер, лепестки, подбор по поводу, горизонтальный каталог, живая открытка, слайдер день/ночь, галерея, формы, cookie
- `assets/images/` — фото

Шрифты: Prata, Onest, Marck Script (Google Fonts).

Сайт разработан в студии [Сайтика](https://studio-psi-olive.vercel.app/).
